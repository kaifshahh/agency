# 🌐 Modern Agency Website – Next.js

A modern, fully responsive agency website built with **Next.js** and **Tailwind CSS**, featuring glassmorphism UI, smooth animations, and interactive effects.

## 🚀 Features

- ⚡ Built with Next.js 16 and React 19
- 🎨 Glassmorphism modern UI design
- 📱 Fully responsive across all devices
- 🌙 Dark & Light mode support
- 🎥 Smooth animations using GSAP & Motion
- 🧩 Reusable and scalable components
- 🌌 Interactive particles and visual effects
- 🧠 Clean and maintainable code structure

## 🛠️ Tech Stack

**Frontend:**

- Next.js
- React
- TypeScript
- Tailwind CSS

**Libraries & Tools:**

- GSAP
- Motion
- tsParticles
- react-parallax-tilt
- react-icons
- lucide-react
- next-themes
- clsx & tailwind-merge
